# Alzheimer Disease Diagnosis using Machine Learning

This project focuses on detecting Alzheimer disease using machine learning algorithms and comparing their performance.

## Project Objective
The main goal is to build and compare different machine learning models to classify Alzheimer disease based on dataset features.

## Machine Learning Models Used
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- K-Nearest Neighbors (KNN)

## Workflow
- Data preprocessing
- Feature selection
- Model training
- Model evaluation and comparison

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Results
The models are compared based on their classification performance to identify the most effective algorithm for Alzheimer detection.

## Note
This project is for educational and research purposes only.
